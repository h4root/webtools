webtools

Небольшие самостоятельные инструменты в одном репозитории. Два браузерных — для локальной сети, четыре консольных. Каждый собирается и запускается у себя.

Браузерные

ws-chat справочник →

Чат для локальной сети: каналы и личные переписки, голосовые каналы и звонки, зашифрованные вложения. Страница не делает ни одного внешнего запроса.

lan-drop справочник →

Передача файлов между устройствами в одной сети прямо из браузера, по WebRTC DataChannel. Сервер сводит пиров, но байты через него не идут.

Консольные

certcheck README в репозитории

Срок и валидность TLS-сертификатов для списка доменов.

dotenv-lint README в репозитории

Сверка .env с .env.example: пропущенные ключи, плейсхолдеры и слабые значения.

leakcheck README в репозитории

Сканер захардкоженных секретов с хуком для pre-commit.

captive-automatic README в репозитории

Автоматическая авторизация в сетях с captive-порталом.

Три консольных написаны без рантайм-зависимостей.
